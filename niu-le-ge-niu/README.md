# 🐮 牛了个牛 ·《牛来》联动版

单文件 HTML5 三消小游戏（「羊了个羊」式玩法），电影《牛来》联动主题。
零依赖、离线可玩、手机 / 平板 / 桌面全适配，全部图片素材内嵌于单个 HTML 文件。

## 目录结构

```
game/                    ← 本仓库（仓库名即 game）
└── niulegeniu/
    ├── index.html       ← 游戏本体（单文件，约 2.2 MB）
    └── README.md        ← 玩法说明 + 代码架构说明（详见该文档）
```

下载 `niulegeniu/index.html`，双击用浏览器打开即可。

## 玩法一句话

点击亮起的方块收进卡槽，凑齐 3 张相同图案即消除；卡槽被占满则失败。
棋盘中部埋有**隐藏重叠井**（多张牌压在同一坐标），挖了才知道有多深。

详细玩法、难度体系与代码架构说明见 [`niulegeniu/README.md`](niulegeniu/README.md)。
